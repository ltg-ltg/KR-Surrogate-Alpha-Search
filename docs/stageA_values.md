# 단계 A 값 산출 결과 (IS 2011~2017만)

- 작성: 2026-11-20
- 재현: `python -m krsas.stage_a --workers 8` → `python -m krsas.calibrate_a`
- 산출: `{data_root}/stage_a/` (`results/`, `excess/`, `meta.json`, `calibration.json`)
- **IS만 봤다.** 패널을 IS 마지막 거래일에서 잘라 계산했으므로 Test·OOS 가격은 메모리에 올라오지 않았다. 숫자는 무작위 기준선과 분포뿐이다. 개별 수식 성과는 이 문서에 없다
- 대상: `pool_v1` 4만 개 전부, 주 유니버스, 주기 3개(일간·주간·월간) × 방향 2개. 방법은 Study 1 `criteria.py`·`calibrate.py`(v1.0-results)를 IS 전용 통과(기준 ①③④)로 옮긴 `krsas.calibrate_a`

## 시그널 필터 (설계서 7.1절)

39,500개 통과. 결측 415개, 상수 85개가 빠졌다. 기준은 Study 1과 같고(유효 비율 ≥ 0.70, 상수일 비율 ≤ 0.10), IS 기간의 주 유니버스 구성 종목-일로 판정했다.

## 마진 적정성 (설계서 11절)

월간 무작위 1,000개 방향 IS IR의 표준편차는 0.43이다. 마진 0.1은 그 0.23배라 0.1~0.5배 안에 든다 → **IR 마진 −0.1을 그대로 둔다.** (주간 0.08배, 일간 0.02배는 범위 밖이지만, 고르지 않은 주기다.)
