## 3. 보고할 관찰 (설계를 바꾸지 않는다)

- 고비용 롱온리라 무작위 수식의 IS IR 중앙값이 음수다 (월간 −0.12, 일간 −1.47). 동일 가중 벤치마크의 IS 연 순수익은 5.1%다 (월간)
- IS 전용 통과로 센 시드 10개에서, 원시 타깃 모델 칸이 무작위보다 많이 찾았다 (44.9 대 26.3). 잔차 타깃은 원시보다 적었다 (26.0 대 44.9). 방향이 Study 1과 반대다. 기준 ①이 학습 타깃과 같은 IS IR이라 모델 칸에 유리한 조건이었다. 단계 B는 Test 기준 ②로 판정한다. 설계서 11절대로 가설 방향·칸·마진은 바꾸지 않는다
- 잔차 타깃은 대표 5개의 구성에 따라 회전율과 강한 음의 상관을 띠는 시드가 있다. 이런 시드에서는 저회전 수식을 몰아 골라 고유 통과가 9~14개로 떨어진다. R2의 분산이 큰 이유이고, 결과 해석 때 함께 보고한다

## 4. 엔진에서 정한 것 (사전 등록에 적는다)

1. 수식 안 횡단면 연산 범위 = 그날 주 유니버스 구성 종목 (최종 순위와 같다)
2. 거래량 0인 날의 필드 = NaN (Study 1 규칙)
3. 시점 기준 척도: 앞에서부터 누적한 수정계수. 횡단면 연산 직전에 노드 단위 지수로 실제 척도로 되돌린다
4. 리밸런싱 달력 = 달의 첫 거래일 + 유니버스 재구성일
5. 보유 수 = round(0.2 × 시그널이 있는 구성 종목 수), 동률은 열 순서
6. 정지 종목을 못 팔아 현금이 모자라면 매수를 같은 비율로 줄인다. 비용은 체결 때 현금에서 낸다. 밀린 매도로 생긴 현금은 다음 리밸런싱까지 둔다
7. 시그널 필터는 IS 기간의 주 유니버스 구성 종목-일로 판정한다 (Study 1 기준값)
8. 유니버스 재구성일 = 6월·12월 첫 거래일, 정보는 직전 거래일까지. 상장 20거래일 미만은 거래대금 평균이 없어 제외한다
