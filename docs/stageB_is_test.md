## 군집 진단과 D1 (단계 B분, 보조)

- x = 2,000개 선택 안의 IS 일별 순 초과수익 |상관| ≥ 0.7 쌍 비율, y = 고유 통과
- 원시 칸 16개 × 153시드: Spearman **−0.72** [−0.77, −0.67] (시드 부트스트랩 95%). 고상관 쌍이 많을수록 고유 통과가 적다
- x 구간별 평균 y: 0.0~0.1 → 61.9, 0.1~0.2 → 49.2, 0.2~0.3 → 38.5, 0.3~0.4 → 27.3. 무작위 기준선은 y 23.7, x 0.10. 관측 범위 0.076~0.369
- 칸별 평균 x: 무작위 0.103. 원시 칸 0.166~0.216 (λ ↑·확장 스키마일수록 낮다). 잔차 칸 0.310(확장·MMR)~0.352(기본·상위 B)
- 잔차 칸은 원시보다 고상관 쌍이 많다. 단계 A에서 본 대로 잔차 타깃이 저회전 수식으로 몰리는 시드가 있어서다
- D1의 판정(단계 B와 C-1 비교)은 단계 C를 할 때 한다
